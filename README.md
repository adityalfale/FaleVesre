# AQUASENSE AI: Smart Water Intelligence Platform

AQUASENSE AI is an intelligent, community-driven water monitoring, conservation, and predictive analytics platform designed for residential societies, urban campuses, and water governance authorities.

## Technology Stack

- Next.js 14 App Router
- React 18 and TypeScript
- Tailwind CSS
- Three.js and React Three Fiber
- Leaflet and OpenStreetMap
- Recharts
- Python, Scikit-learn, NumPy and Pandas
- PostgreSQL and Supabase
- ESP32 IoT integration

## Main Features

- 3D Underground Borewell Simulation
- Interactive GIS Aqua Map
- AI Water Forecasting
- Groundwater Monitoring
- Overhead and Sump Tank Monitoring
- Tanker Supply Scheduling
- Rainwater Harvesting Calculator
- Community Leakage Reporting
- ESP32 IoT Sensor Integration
- Reports and CSV Export
- Role-Based Access Control
